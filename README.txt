拾音 · 本地音频/视频/链接转文字 v1.0.0
=====================================
开口即录，落笔成文 —— 文件不出电脑的语音转文字工具。

【快速开始】
1. 安装 Node.js 18+（https://nodejs.org/zh-cn/download）
2. 双击「启动拾音.bat」→ 浏览器自动打开 http://127.0.0.1:18900
3. 首次使用：右侧「模型管理」下载一个模型（推荐 turbo）
4a. 本地文件：把音频/视频拖进页面 → 选模型 → 点「开始识别」
4b. 视频链接：粘贴 B站/YouTube/抖音/快手链接 → 自动下载转写（有官方字幕直接秒出）

【常用功能】
- 全文 txt / 字幕 srt / 网页字幕 vtt 三种输出，在线编辑即存
- 链接蒸馏：B站/YouTube/抖音/快手，有官方/AI 字幕 1 秒出结果
- 自动落盘：转写完成归档 txt/srt/vtt/meta 四件套到收件箱（默认 桌面/拾音收件箱，设置面板可改）
- 热词纠错：设置热词表修正专有名词误转（AI 总结等可选配置见设置面板）
- 字幕跟读：点击任意字幕行跳转播放，当前行高亮；字幕工具支持整体时间偏移
- VAD 跳过静音：长音频/播客显著加速
- 失败任务一键重试；后台完成标签闪烁提醒；批量多链接一次入队

【停止服务】
双击「停止拾音.bat」（按端口精确停止，不误伤其它程序）。

【常见问题】
- 打不开？确认已装 Node.js 18+，浏览器访问 http://127.0.0.1:18900
- 识别慢？本地 CPU 转写为实时语速 2~4 倍属正常；可换 small 模型或开启 VAD
- 抖音/快手链接不可用？需 npm install 安装 playwright-core（可选能力）
- 图标没更新？浏览器 Ctrl+F5 强刷；PWA 固定图标取消固定再重固定

【隐私】
纯本地工具：服务只监听 127.0.0.1，音频与模型均不出电脑，仅下载模型/视频链接内容时联网；AI 总结需自配端点（默认关闭，开启后内容发往所填端点）。
